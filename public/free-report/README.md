# public/free-report

Google profile thumbnails used on the example Free Google Report cards
(`/free-report/view` with no id). Pulled from Serper `/maps` `thumbnailUrl`.
Live reports use each shop’s own `photoUrl` when the API has one.

`map.jpg` is one Tampa location snapshot reused on the three Map Pack phones.
Live reports replace it with `mapImageUrl` (Google Static Maps or an Esri/OSM
mosaic). The view page keeps a little colour so water and roads still read.
