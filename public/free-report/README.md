# public/free-report

Google profile thumbnails used on the example Free Google Report cards
(`/free-report/view` with no id). Pulled from Serper `/maps` `thumbnailUrl`.
Live reports use each shop’s own `photoUrl` when the API has one.

`map.jpg` is one Tampa location snapshot reused on the Map Pack SERP mock,
both geo grids, and the “where we search from” cards. Saved greyscale. Live reports replace it with `mapImageUrl`
(one simplified Google Static Maps image or a quieter Esri/OSM mosaic). The
view page greyscales every map, then overlays a shop pin on “address shown”
and a service-area graphic on “address hidden”.
